# 🌌 GLASSVERSE

A magical glass universe exploration game built for Android.

## Features
- 🏝 Explore floating islands
- 💎 Collect crystals and resources
- 🐾 Discover 6 unique fantasy creatures
- 🧩 Solve crystal sequence puzzles
- 🔮 Find hidden secret areas
- 🌀 Enter mysterious portals
- 🏗 Build structures and decorations
- 📜 Complete quests and earn rewards
- 🏆 Unlock achievements
- ⚡ Experience random sky events
- 🎵 Ambient music and sound effects
- 📳 Haptic feedback support

## Build

```bash
chmod +x gradlew
./gradlew assembleDebug
